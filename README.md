# Lorem Ipsum
Lorem Ipsum is the name of my Discord bot I have. The purpose of the bot is to experiment and do what I desire. Most of the code is written in C using the Concord API library. Please go support them. https://github.com/Cogmasters/concord
I do use a little bit of everything and desire to experiment with API, but now it's mostly C.

I release bot code as ELF files Where you can download it, make it executable `chmod +x binary` and then run it. On first startup, it'll write a README and a config file. The config file is where you put your bot token and other needed config.
At the time of me updating this, v1.0.1 is the latest release. Since then, I have added sub-commands to the file. I did it because I may possibly create a deb package. Otherwise, run it as normal. The only sub-command right now is `./binary -s` which simply starts it in a hard-coded spot for the bot config. It makes it expect a bot config in `/home/discord-bot/bot_config.conf`. I'll add more sub-commands later.
